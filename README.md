# 🚀 PASS CBT - 멀티 자격증 국가공인 CBT 수험 시뮬레이터

한국산업인력공단, K-DATA, 대한상공회의소 등 실전 CBT 시험 환경을 100% 동일하게 구현한 초경량 개인 맞춤형 멀티 자격증 CBT 수험 플랫폼입니다.

---

## 📌 주요 특징

- **6종 국가공인 자격증 지원**:
  1. **SQLD (SQL 개발자)**: 2020~2026 기출복원 20문항 / 과락 분석
  2. **ADsP (데이터분석 준전문가)**: 2020~2026 기출복원 20문항 / 과락 분석
  3. **정보처리기사 필기**: 정기 기출 20문항 / 5과목 과락 분석
  4. **컴퓨터활용능력 1급 필기**: 3과목 과락 분석
  5. **산업안전기사 필기**: 정기 기출 20문항
  6. **정보처리기사 실기**: 주관식 단답형/코드추적 + 자가 채점 시스템
- **수험 최적화 UI/UX**:
  - **iOS 리퀴드 글래스(Liquid Glass)** 및 앰비언트 글로우 테마
  - **다크 모드 (`🌙 / ☀️`) 원클릭 토글** (고대비 WCAG AAA 가독성)
  - **터미널 코드 윈도우**: SQL, Java, C, Python 등 고대비 에메랄드 모노스페이스 글꼴 지원
  - **모바일 반응형 최적화**: 큼직한 지문/보기 폰트, 오타 없는 56px+ 터치 타겟
  - **핸즈프리 오디오 학습**: 에어팟/이어폰으로 이동 중 문제/보기/정답/해설 연속 듣기(TTS) 지원
- **100% 로컬 프라이버시 & 초경량 아키텍처**:
  - 무거운 외부 DB나 복잡한 상태관리 라이브러리 없이 순수 React와 `localStorage`만으로 작동
  - 인터넷 없이도 더블클릭만으로 즉시 실행 가능한 단일 HTML 파일 (`pass_cbt.html`)

## 📁 주요 디렉토리 구조

```
pass/
├── pass_cbt.html          # ⭐ 인터넷 없이 바로 실행 가능한 단일 HTML 배포본
├── index.html             # Vite 개발용 진입점
├── src/
│   ├── components/        # React 컴포넌트 (QuestionCard, OMRCard, ExamHome 등)
│   ├── data/              # 시험 규격(exams.json) 및 6종 기출 문제 JSON
│   └── index.css          # 리퀴드 글래스 및 고대비 다크모드 스타일
├── scripts/
│   └── parse_cbt_text.py  # 기출문제 수집 및 표준 JSON 자동 변환 파이프라인
└── package.json           # 빌드 및 의존성 설정
```

## 💻 로컬 개발 및 실행 방법

### 1) 바로 실행하기 (가장 간단한 방법)
프로젝트 루트의 `pass_cbt.html` 파일을 브라우저로 열면 즉시 실행됩니다.

### 2) 개발 서버 실행 (코드 수정 시)
```bash
# 패키지 설치
npm install

# 로컬 개발 서버 실행 (Hot Reload)
npm run dev

# 단일 파일 배포본으로 빌드
npm run build && cp dist/index.html pass_cbt.html
```
