1. GoF(Gang of Four) 디자인 패턴 중 생성(Creational) 패턴에 해당하지 않는 것은?
① Abstract Factory
② Builder
③ Adapter
④ Prototype
[정답] 3
[해설] Adapter 패턴은 클래스의 인터페이스를 사용자가 기대하는 다른 인터페이스로 변환하는 '구조(Structural) 패턴'입니다. 생성 패턴은 추상팩토리, 빌더, 팩토리메소드, 프로토타입, 싱글톤입니다.

2. 다음 파이썬(Python) 코드의 실행 결과로 올바른 것은?
```python
data = [10, 20, 30, 40, 50]
result = [x * 2 for x in data if x > 25]
print(len(result), result[0])
```
① 3 60
② 2 50
③ 3 50
④ 2 60
[정답] 1
[해설] 25보다 큰 원소 [30, 40, 50]에 대해 각 원소에 2를 곱하여 [60, 80, 100]이 됩니다. len(result)는 3이며, result[0]은 60입니다.

3. 소프트웨어 테스트 기법 중 프로그램 내부 구조나 소스코드를 보지 않고, 요구사항 명세서를 기반으로 기능의 정상 동작 여부를 확인하는 테스트는?
① 화이트박스 테스트 (White Box Test)
② 블랙박스 테스트 (Black Box Test)
③ 정적 테스트 (Static Test)
④ 구조 기반 테스트 (Structural Test)
[정답] 2
[해설] 명세 기반 테스트이자 내부 구조를 모르는 상태에서 입출력을 검증하는 테스트는 '블랙박스 테스트(Black Box Test)'입니다. 동등분할, 경계값분석 등이 대표적입니다.

4. 관계형 데이터베이스에서 외래키(Foreign Key) 값은 참조하는 테이블의 기본키 값과 일치하거나 NULL이어야 한다는 규칙은?
① 개체 무결성 (Entity Integrity)
② 참조 무결성 (Referential Integrity)
③ 도메인 무결성 (Domain Integrity)
④ 키 무결성 (Key Integrity)
[정답] 2
[해설] 릴레이션 간의 관계에서 외래키는 참조 릴레이션의 기본키 값을 참조하거나 NULL 값을 가져야 한다는 규칙은 '참조 무결성' 제약조건입니다.

5. 비대칭키(공개키) 암호화 알고리즘에 해당하지 않는 것은?
① RSA
② ECC
③ AES
④ ElGamal
[정답] 3
[해설] AES는 대표적인 대칭키(비밀키) 블록 암호 알고리즘(128, 192, 256비트)입니다. RSA, ECC, ElGamal은 공개키(비대칭키) 알고리즘입니다.

6. 객체지향 설계 5대 원칙(SOLID) 중 '하위 클래스는 상위 클래스를 대체할 수 있어야 한다'는 원칙은?
① 단일 책임 원칙 (SRP)
② 개방 폐쇄 원칙 (OCP)
③ 리스코프 치환 원칙 (LSP)
④ 의존 역전 원칙 (DIP)
[정답] 3
[해설] LSP(Liskov Substitution Principle)는 자식 클래스는 최소한 부모 클래스가 할 수 있는 일은 수행할 수 있어야 한다는 대체 가능성의 원칙입니다.

7. UML 다이어그램 중 시스템의 정적 구조를 표현하는 구조적(Structural) 다이어그램에 해당하는 것은?
① 시퀀스 다이어그램 (Sequence Diagram)
② 유스케이스 다이어그램 (Use Case Diagram)
③ 클래스 다이어그램 (Class Diagram)
④ 상태 다이어그램 (State Diagram)
[정답] 3
[해설] 클래스 다이어그램은 객체 지향 모델의 정적 구조를 표현하는 대표적인 구조 다이어그램입니다. 시퀀스, 유스케이스, 상태 다이어그램은 행위(Behavioral) 다이어그램입니다.

8. 화이트박스 테스트 검증 기준(커버리지) 중 소스코드의 모든 분기(Branch)에서 참(True)과 거짓(False)이 적어도 한 번씩 수행되도록 보장하는 기준은?
① 구문 커버리지 (Statement Coverage)
② 결정 커버리지 (Decision / Branch Coverage)
③ 조건 커버리지 (Condition Coverage)
④ 다중 조건 커버리지 (Multiple Condition Coverage)
[정답] 2
[해설] 결정(분기) 커버리지는 각 조건문 전체의 최종 결과가 참/거짓으로 적어도 한 번씩 실행되도록 하는 테스트 기준입니다.

9. 소프트웨어 개발 생명주기(SDLC) 모형 중 위험 분석(Risk Analysis)을 병행하며 점진적으로 시스템을 개발해 나가는 모형은?
① 폭포수 모형 (Waterfall Model)
② 나선형 모형 (Spiral Model)
③ 프로토타입 모형 (Prototyping Model)
④ 애자일 모형 (Agile Model)
[정답] 2
[해설] 나선형 모형은 계획수립 → 위험분석 → 개발및검증 → 고객평가의 4단계를 반복하며 대규모 시스템의 위험을 최소화하는 모델입니다.

10. 트랜잭션의 4대 특성(ACID) 중 '트랜잭션이 성공적으로 완료되면 그 결과는 영구적으로 데이터베이스에 반영되어야 한다'는 원칙은?
① 원자성 (Atomicity)
② 일관성 (Consistency)
③ 격리성 (Isolation)
④ 지속성 (Durability)
[정답] 4
[해설] 영구성/지속성(Durability)은 트랜잭션의 커밋이 성공하면 시스템 오류가 발생하더라도 그 상태가 영구히 보존되어야 한다는 특성입니다.

11. 다음 C언어 프로그램의 출력 결과로 올바른 것은?
```c
#include <stdio.h>
int main() {
    int a = 5, b = 2;
    printf("%d", a % b + a / b);
    return 0;
}
```
① 1
② 2
③ 3
④ 4
[정답] 3
[해설] 5 % 2의 나머지는 1이고, 5 / 2의 정수 몫은 2입니다. 따라서 1 + 2 = 3이 출력됩니다.

12. 다음 Java 코드에서 `super` 키워드의 주된 용도로 가장 올바른 것은?
```java
class Child extends Parent {
    Child() { super(); }
}
```
① 현재 인스턴스 자신의 멤버를 참조
② 부모(상위) 클래스의 생성자 또는 멤버를 명시적으로 호출
③ 인터페이스를 상속받기 위한 키워드
④ 동기화(Synchronization) 블록을 선언
[정답] 2
[해설] `super()`는 자식 클래스에서 상위(부모) 클래스의 생성자나 메서드를 호출할 때 사용하는 참조 키워드입니다.

13. 페이지 교체 알고리즘 중 가장 오랫동안 참조되지 않은 페이지를 교체 대상으로 선택하는 알고리즘은?
① FIFO (First In First Out)
② LRU (Least Recently Used)
③ LFU (Least Frequently Used)
④ OPT (Optimal)
[정답] 2
[해설] LRU는 최근에 가장 오랫동안 사용되지 않은 페이지를 교체하는 알고리즘입니다. LFU는 참조 횟수가 가장 적은 페이지를 교체합니다.

14. IPv4 주소 체계에서 C 클래스(Class C)의 기본 서브넷 마스크(Default Subnet Mask)는?
① 255.0.0.0
② 255.255.0.0
③ 255.255.255.0
④ 255.255.255.255
[정답] 3
[해설] A클래스는 255.0.0.0, B클래스는 255.255.0.0, C클래스는 255.255.255.0 입니다.

15. 네트워크 프로토콜 중 IP 주소를 물리적 하드웨어 주소인 MAC 주소로 변환(해석)해주는 프로토콜은?
① ARP (Address Resolution Protocol)
② RARP (Reverse ARP)
③ DHCP
④ ICMP
[정답] 1
[해설] IP 주소 → MAC 주소 변환은 ARP입니다. 반대로 MAC 주소 → IP 주소 변환은 RARP입니다.

16. 보안 공격 유형 중 공격자가 패킷의 출발지 IP 주소를 조작하여 신뢰받는 호스트인 것처럼 위장하는 기법은?
① 스니핑 (Sniffing)
② 스푸핑 (Spoofing)
③ 스미싱 (Smishing)
④ 피싱 (Phishing)
[정답] 2
[해설] 스푸핑(Spoofing)은 '속이다'라는 뜻으로 IP, MAC, DNS 주소 등을 속여 시스템에 비인가 접근하는 기법입니다. 스니핑은 몰래 엿듣는 도청입니다.

17. 접근 통제(Access Control) 모델 중 주체의 직무나 역할(Role)에 따라 시스템 자원에 대한 권한을 부여하는 모델은?
① 강제적 접근 통제 (MAC)
② 임의적 접근 통제 (DAC)
③ 역할 기반 접근 통제 (RBAC)
④ 규칙 기반 접근 통제 (RuBAC)
[정답] 3
[해설] RBAC(Role-Based Access Control)은 사용자의 역할과 조직 내 권한에 기반하여 자원 접근 권한을 할당하므로 대규모 기업 환경 관리에 유리합니다.

18. 세션 하이재킹(Session Hijacking) 공격을 방지하기 위한 보안 대책으로 가장 적절한 것은?
① 세션 키를 URL 파라미터에 그대로 노출한다.
② 세션 만료 시간(Timeout)을 설정하고 HTTPS(SSL/TLS) 암호화 통신을 강제한다.
③ IP 인증을 비활성화한다.
④ 비밀번호 변경 주기를 10년으로 연장한다.
[정답] 2
[해설] HTTPS 암호화로 패킷 스니핑을 차단하고, 세션 유효시간을 짧게 설정하며 세션 ID를 주기적으로 재발급하는 것이 핵심 방어책입니다.

19. 소프트웨어 형상 관리(SCM)의 주요 활동에 해당하지 않는 것은?
① 형상 식별 (Identification)
② 형상 통제 (Control)
③ 형상 감사 (Audit)
④ 하드웨어 조립 (Hardware Assembly)
[정답] 4

20. 릴레이션에서 모든 결정자(Determinant)가 후보키(Candidate Key)여야 한다는 조건을 만족하는 정규형은?
① 제1정규형
② 제2정규형
③ 제3정규형
④ 보이스-코드 정규형 (BCNF)
[정답] 4
[해설] BCNF(Boyce-Codd Normal Form)는 3정규형을 만족하면서 모든 결정자가 후보키인 정규형으로, '강한 제3정규형'이라고도 합니다.
